# Support

## How to file issues and get help

This project uses [GitHub Issues](../../issues) to track bugs and feature requests. Please search the
existing issues before filing new ones to avoid duplicates. For new issues, file your bug or feature
request as a new issue.

If you are challenging a measurement rather than reporting a defect, please include the specific
comparison from [`docs/report.md`](docs/report.md) and what you believe it should be. The per-query
data behind every published number is committed in [`results/`](results).

## Support policy

**This is a sample, not a supported product.** It is provided as-is to demonstrate and quantify a
retrieval technique. It carries no SLA, and Microsoft Support does not cover it.
